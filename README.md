## Featured projects

### 🚦 Smart Traffic Management System
A real-time traffic management prototype designed to detect emergency vehicles and support adaptive traffic-light control.

- **Hardware & connectivity:** Raspberry Pi 4, ESP32, Heltec LoRa, RFID/NFC, cameras, and MQTT.
- **AI / vision:** vehicle detection and traffic monitoring using YOLOv8n.
- **Goal:** explore emergency-vehicle prioritization and traffic-flow optimization.

### 🤖 All-Terrain Robot
An engineering competition robot developed around an ESP32-based control system.

- Integrated motor drivers, power management, and embedded control.
- Built and tested as part of robotics competitions.
- The team achieved two competition wins and one second-place finish.

### 🌡️ IoT Smart Valve Control
A temperature-oriented monitoring and control prototype developed during an engineering internship.

- ESP8266-based device control.
- Remote operation through a mobile application using Blynk.
- Demonstrates the integration of embedded hardware and IoT connectivity.

### 💡 Smart Light Control
An IoT lighting-control project connecting an Android application to an ESP8266 device through MQTT.

### 🌐 Web Development Projects
Web projects built with technologies including HTML, CSS, JavaScript, and PHP, including a website for a local gym.
